Read PDFs without the clutter.

OpenPdfStudio is a fast desktop PDF viewer for Windows, Linux, and macOS. It renders pages with PDFium, the engine behind Chrome's PDF viewer, and keeps the interface out of your way.

Everything you need to read a PDF

Built for reading, not for selling you a subscription.

Smooth scrolling

Scroll through every page continuously. Pages render in the background, so the window stays responsive.

Zoom and fit

Zoom from 25% to 400%, or snap to fit width, fit page, or actual size.

Select and copy text

Switch to the select tool, drag across text on any page, and copy it to the clipboard.

Tabs

Open several documents at once and switch between them in tabs.

Recent and starred files

The home screen keeps your recent files close, and you can star the ones you return to.

Password-protected PDFs

Encrypted documents open with a password prompt. Nothing is stored or sent anywhere.

Rotate and pan

Rotate the view in 90 degree steps and drag pages around with the hand tool.

Five themes

Dark, Light, System, Midnight, and High Contrast. Your choice is remembered.

Page thumbnails

A thumbnail sidebar shows where you are and jumps to any page with one click.

Keyboard shortcuts

Ctrl + OOpen a file
Ctrl + WClose the current tab
Ctrl + +Zoom in
Ctrl + -Zoom out
Ctrl + CCopy selected text

Download

Each download is a single zip with everything included. You don't need to install .NET. Unzip it and run OpenPdfStudio.

Windows 64-bit, Windows 10 or later Linux 64-bit, x64 macOS Apple Silicon (M1 and later)

The macOS build is not signed yet, so macOS will warn the first time you open it. Right-click the app and choose Open to run it anyway. All builds are on the Releases page.
