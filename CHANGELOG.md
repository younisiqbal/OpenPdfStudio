# Changelog

All notable changes to OpenPdfStudio are listed here.

## [0.5.0] - 2026-11-13

### Compare

- Side-by-side PDF compare from Home, with Sync for linked scroll
- Text diffs on the page: **Differences** highlights changed words in red on both panes; **Matching** highlights shared words in green; optional no highlights
- **Whole documents** or **Selected pages** scope (pick left/right page, Use current, Compare)
- Sync in selected-pages mode keeps vertical position without forcing the same page index
- Redesigned Compare toolbar (two rows, clearer secondary buttons)
- Launch with `--compare left.pdf right.pdf`; second-instance handoff supports compare
- Fix crash when opening the Compare file picker dialog

## [0.4.1] - 2026-11-13

- Show the assembly/build version in the UI (footer and About)
- Remove the Add Comments card from the Home screen

## [0.4.0] - 2026-11-12

- PDF to Word and Word to PDF conversion
- Foxit-style document ribbon

## [0.3.0] - 2026-11-12

- Rebuild document view around a two-row command bar
- Custom title bar with square corners
- Hide app chrome on the home screen
- Light New Task home redesign and Recent sidebar
- Open PDFs dropped onto the window
- Organize pages inside the document tab
- Organize, Split, and Merge on the Edit ribbon
- Page layouts, bookmarks, snapshot, settings, and page tools

## [0.2.0] - 2026-10-28

- Word-style ribbon and customizable left rail
- Comment tools (notes, typewriter, text boxes, markup) with hover bar and colours
- Installers that register PDF opening (portable zips kept)
- Page context menu, paste/save, Read Mode, Full Screen, Print
- Page rulers (Ctrl+R)
- Find box, top search, and Advanced Search
- Move viewer tools and thumbnails to the left rail

## [0.1.0] - 2026-10-09

- Initial product website and release workflows
- Core PDF viewing and early studio features
